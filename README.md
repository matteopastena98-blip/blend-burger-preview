# Blend Burger — anteprima di design

[Apri il sito](https://matteopastena98-blip.github.io/blend-burger-preview/)

Candidata di design del 21 ottobre 2026, condivisa per raccogliere feedback.
Anteprima non ufficiale, non è il sito pubblico definitivo del locale.

Home, menu e archivio in italiano e inglese. Fotografie e marchio appartengono ai rispettivi titolari; nessuna licenza di riutilizzo dei contenuti viene concessa da questo repository.

Questo repository contiene soltanto la build statica condivisibile. Documenti interni, ricerche, pannello CMS e credenziali non sono inclusi. Le pagine sono marcate `noindex`.

GitHub Pages pubblica il branch `main`, directory `/`. `.nojekyll` preserva i file `_astro`. I percorsi sono adattati al sottopercorso del repository.
